# BaleTani Assets Directory

Folder ini untuk menyimpan semua asset seperti gambar, logo, dan icon untuk website BaleTani.

## 📁 Struktur Folder

### `/logos/`
**LOGO BALETANI - TARUH DISINI!**
- `logo-main.png` - Logo utama BaleTani (untuk header, ukuran besar)
- `logo-small.png` - Logo kecil (untuk favicon, button)
- `logo-white.png` - Logo putih (untuk background gelap)
- `logo-text.png` - Logo dengan text "BaleTani"
- `favicon.ico` - Icon website

**Format yang direkomendasikan:**
- PNG dengan background transparan
- SVG untuk scalability terbaik
- Ukuran: 200x80px (main), 64x64px (small)

### `/products/`
**FOTO PRODUK - UNTUK CATALOG**
Struktur penamaan: `[kategori]-[nama-produk]-[nomor].jpg`

**Sayuran:**
- `sayuran-bayam-1.jpg` - Bayam segar organik
- `sayuran-tomat-cherry-1.jpg` - Tomat cherry premium
- `sayuran-kangkung-1.jpg` - Kangkung hidroponik
- `sayuran-sawi-1.jpg` - Sawi hijau fresh

**Buah-buahan:**
- `buah-apel-fuji-1.jpg` - Apel Fuji import
- `buah-pisang-cavendish-1.jpg` - Pisang Cavendish
- `buah-jeruk-pontianak-1.jpg` - Jeruk Pontianak

**Daging & Unggas:**
- `daging-ayam-kampung-1.jpg` - Ayam kampung segar
- `daging-sapi-premium-1.jpg` - Daging sapi premium

**Seafood:**
- `seafood-salmon-fillet-1.jpg` - Ikan salmon fillet
- `seafood-udang-vaname-1.jpg` - Udang vaname jumbo

**Tips Foto Produk:**
- Resolusi minimal 600x600px
- Background putih/netral
- Pencahayaan natural
- Multiple angles (1-4 foto per produk)

### `/hero/`
**GAMBAR HERO SECTION**
- `hero-main.jpg` - Hero utama landing page (1200x600px)
- `hero-about.jpg` - Tentang kami section (800x500px)
- `hero-fresh-market.jpg` - Mixed fresh products display

### `/categories/`
**GAMBAR KATEGORI**
- `kategori-sayuran.jpg` - Representasi sayuran (400x300px)
- `kategori-buah.jpg` - Representasi buah-buahan
- `kategori-daging.jpg` - Representasi daging & unggas
- `kategori-seafood.jpg` - Representasi seafood

### `/icons/`
**ICON & ILUSTRASI**
- Custom icons untuk fitur khusus
- Social media icons
- Service icons (truck, shield, etc.)

## 🎨 Panduan Style

### Warna BaleTani:
- **Primary Green**: #22C55E (Green-500)
- **Secondary Orange**: #FB923C (Orange-400)
- **Neutral Gray**: #6B7280 (Gray-500)

### Style Guide:
- **Natural & Fresh** - Tampilkan kesegaran produk
- **Clean & Minimalist** - Background bersih, fokus pada produk
- **High Quality** - Resolusi tinggi, pencahayaan bagus
- **Consistent** - Style yang seragam untuk semua produk

## 📷 Tips Fotografi Produk:

### Equipment:
- Kamera/smartphone dengan kualitas bagus
- Tripod untuk stabilitas
- Softbox/ring light untuk pencahayaan

### Setting:
- **Background**: Putih/light gray
- **Lighting**: Natural light atau softbox
- **Angle**: Multiple angles (depan, samping, detail)
- **Composition**: Rule of thirds, fill the frame

### Post-processing:
- Color correction untuk konsistensi
- Background removal jika perlu
- Resize ke ukuran yang tepat
- Compress untuk web (< 500KB per file)

## 🔧 Technical Requirements:

### Format File:
- **Logo**: PNG/SVG
- **Photos**: JPG/PNG
- **Icons**: SVG/PNG

### Ukuran File:
- Logo: < 100KB
- Hero images: < 1MB
- Product photos: < 500KB
- Category images: < 300KB

### Naming Convention:
- Lowercase
- Dash separated (kebab-case)
- Descriptive names
- No spaces or special characters
