## 1. PENDAHULUAN

### 1.1 Tentang Balétani Fresh Market

Balétani adalah platform pasar segar online yang menyediakan hasil pertanian berkualitas tinggi langsung dari petani lokal ke rumah Anda. Dengan tagline **"Dari kebun ke Balé, dari Balé ke rumahmu"**, Balétani berkomitmen menyediakan produk segar dengan harga terjangkau.

### 1.2 Tujuan Manual Book

Manual book ini dibuat untuk membantu pelanggan Balétani memahami cara menggunakan aplikasi web Balétani secara lengkap, mulai dari registrasi hingga melakukan pemesanan dan melacak status pesanan.

### 1.3 Persyaratan Sistem

Untuk menggunakan aplikasi Balétani dengan optimal, pastikan:

- **Browser:** Google Chrome, Mozilla Firefox, Safari, atau Microsoft Edge versi terbaru
- **Koneksi Internet:** Stabil untuk memuat gambar produk
- **Nomor Telepon:** Aktif untuk registrasi dan konfirmasi pesanan via WhatsApp
- **Aplikasi WhatsApp:** Terinstall untuk menerima konfirmasi pesanan

## 2. MEMULAI MENGGUNAKAN APLIKASI

### 2.1 Halaman Landing (Beranda Publik)

**Gambar 2.1: Halaman Landing**

Halaman Landing adalah halaman pertama yang Anda lihat saat mengakses website Balétani tanpa login.

**Fungsi Halaman Landing:**

- Menampilkan informasi umum tentang Balétani Fresh Market
- Menampilkan **Hero Section** dengan pesan utama dan animasi menarik
- Menampilkan **Produk Unggulan** dengan carousel auto-play yang berganti setiap 5 detik
- Menampilkan **Daftar Kategori Produk** yang tersedia
- Menyediakan tombol navigasi ke halaman Login dan Register
- Menampilkan **Keunggulan Layanan** Balétani (pengiriman cepat, produk segar, dll.)

**Elemen-elemen pada Halaman Landing:**

| No  | Elemen                | Keterangan                                 |
| --- | --------------------- | ------------------------------------------ |
| 1   | Logo Balétani         | Klik untuk kembali ke halaman utama        |
| 2   | Menu Navigasi         | Produk, Promo, Kategori, Kontak            |
| 3   | Tombol Login/Register | Akses ke halaman autentikasi               |
| 4   | Hero Section          | Banner utama dengan CTA "Mulai Belanja"    |
| 5   | Carousel Produk       | Produk unggulan dengan navigasi kiri/kanan |
| 6   | Grid Kategori         | Kategori produk dengan ikon visual         |
| 7   | Footer                | Informasi kontak dan link penting          |

**Catatan:** Tanpa login, Anda dapat melihat produk dan promo, namun tidak dapat menambahkan ke keranjang atau melakukan pembelian.

---

### 2.2 Registrasi Akun Baru

**Gambar 2.2: Halaman Registrasi**

Untuk dapat berbelanja di Balétani, Anda harus memiliki akun terlebih dahulu.

**Langkah-langkah Registrasi:**

1. Klik tombol **"Daftar"** atau **"Register"** pada navbar atau halaman landing
2. Anda akan diarahkan ke halaman registrasi
3. Isi form registrasi dengan data berikut:

| No  | Field               | Keterangan                       | Validasi                                  |
| --- | ------------------- | -------------------------------- | ----------------------------------------- |
| 1   | Nama Lengkap        | Nama sesuai identitas            | Minimal 2 karakter, hanya huruf dan spasi |
| 2   | Nomor Telepon       | Format: 08xx, 62xxx, atau +62xxx | 10-15 digit, harus valid                  |
| 3   | Password            | Kata sandi akun                  | Minimal 8 karakter                        |
| 4   | Konfirmasi Password | Ulangi password                  | Harus sama dengan password                |

4. Sistem akan menampilkan **Indikator Kekuatan Password**:

   - Sangat Lemah (merah)
   - Lemah (merah muda)
   - Sedang (kuning)
   - Kuat (hijau)
   - Sangat Kuat (hijau tua)

5. Klik tombol **"Daftar"**
6. Jika berhasil, Anda akan diarahkan ke halaman Login dengan notifikasi sukses

**Validasi yang Diterapkan:**

- Nomor telepon akan dinormalisasi ke format 62xxx (tanpa tanda +)
- Nama tidak boleh mengandung karakter khusus berbahaya
- Password disimpan dalam bentuk terenkripsi (hash)

**Pesan Error Umum:**

- "Nomor telepon sudah terdaftar" - Nomor HP sudah digunakan akun lain
- "Format nomor telepon tidak valid" - Format HP tidak sesuai
- "Password minimal 8 karakter" - Password terlalu pendek

---

### 2.3 Login ke Akun

**Gambar 2.3: Halaman Login**

Setelah memiliki akun, Anda dapat login untuk mulai berbelanja.

**Langkah-langkah Login:**

1. Klik tombol **"Masuk"** atau **"Login"** pada navbar
2. Anda akan diarahkan ke halaman login dengan logo Balétani
3. Isi form login:

| No  | Field         | Keterangan                                                  |
| --- | ------------- | ----------------------------------------------------------- |
| 1   | Nomor Telepon | Nomor HP yang didaftarkan (format 08xx, 62xxx, atau +62xxx) |
| 2   | Password      | Kata sandi akun Anda                                        |

4. Klik ikon **mata** untuk menampilkan/menyembunyikan password
5. Klik tombol **"Masuk"**
6. Jika berhasil, Anda akan diarahkan ke **Halaman Beranda Customer** (/home)

**Fitur Login:**

- **Remember Me:** Sesi login akan dipertahankan menggunakan token JWT
- **Token Expiry Checker:** Sistem otomatis memeriksa validitas token
- **Rate Limiter:** Pembatasan percobaan login untuk keamanan

**Pesan Error Umum:**

- "Nomor telepon atau password salah" - Kredensial tidak cocok
- "Akun tidak ditemukan" - Nomor HP belum terdaftar
- "Terlalu banyak percobaan, coba lagi nanti" - Rate limit tercapai

## 4. MENJELAJAHI PRODUK

### 4.1 Katalog Produk

**Gambar 4.1: Halaman Katalog Produk**

Halaman Katalog menampilkan semua produk yang tersedia dengan fitur filter dan pencarian ala Tokopedia.

**Akses:** Klik menu **"Produk"** pada navbar atau tombol **"Mulai Belanja"**

**Layout Halaman:**

| Posisi         | Elemen             | Keterangan                                                 |
| -------------- | ------------------ | ---------------------------------------------------------- |
| Header         | Search Bar + Judul | Pencarian produk dengan placeholder "Cari produk segar..." |
| Kiri (Desktop) | Sidebar Filter     | Filter kategori dan sorting                                |
| Tengah         | Grid Produk        | Kartu produk dalam layout responsive                       |
| Bawah          | Pagination         | Navigasi halaman produk                                    |

**Fitur Filter dan Pencarian:**

1. **Search Bar:**

   - Ketik nama produk yang dicari
   - Pencarian menggunakan **debounce** (delay 500ms) untuk menghemat request
   - Klik ikon X untuk menghapus pencarian

2. **Filter Kategori:**

   - Pilih "Semua Kategori" atau kategori spesifik
   - Gunakan radio button untuk memilih satu kategori
   - Filter otomatis diterapkan tanpa reload halaman

3. **Sorting (Urutan):**

   - Terbaru (default)
   - Harga Terendah
   - Harga Tertinggi
   - Nama A-Z
   - Nama Z-A

4. **Reset Filter:**
   - Klik tombol "Reset" untuk menghapus semua filter

**Komponen Kartu Produk (ProductCard):**

| No  | Elemen           | Keterangan                                       |
| --- | ---------------- | ------------------------------------------------ |
| 1   | Gambar Produk    | Thumbnail dengan lazy loading                    |
| 2   | Badge Diskon     | Tampil jika ada diskon aktif (contoh: "20% OFF") |
| 3   | Nama Produk      | Maksimal 2 baris dengan ellipsis                 |
| 4   | Harga Asli       | Dicoret jika ada diskon                          |
| 5   | Harga Final      | Harga setelah diskon (jika ada)                  |
| 6   | Info Stok        | "Tersisa X" atau "Stok Habis"                    |
| 7   | Tombol Keranjang | Tambah ke keranjang (perlu login)                |

**Fitur Mobile:**

- Pada layar mobile, sidebar filter disembunyikan
- Klik ikon **filter (SlidersHorizontal)** untuk membuka filter drawer dari bawah
- Badge menunjukkan jumlah filter aktif

**Alur Data (FE → BE):**

1. Frontend memanggil `GET /api/public/products` dengan query params:
   - `search`: kata kunci pencarian
   - `category_id`: ID kategori
   - `sortBy`: jenis sorting
   - `page`: halaman saat ini
   - `limit`: jumlah per halaman
2. Backend memproses query dan mengembalikan data produk + pagination
3. Frontend merender hasil dalam grid

- Nilai minimum: 1
- Nilai maksimum: sesuai stok tersedia

| Tombol              | Fungsi                                              |

1. Frontend memanggil `GET /api/public/products/:id`
2. Backend mengembalikan detail produk termasuk:

## 5. KERANJANG BELANJA

### 5.1 Menambahkan Produk ke Keranjang

**Gambar 5.1: Menambahkan ke Keranjang**

Ada beberapa cara menambahkan produk ke keranjang:

**Cara 1: Dari Kartu Produk**

1. Hover pada kartu produk (desktop) atau tap (mobile)
2. Klik ikon **keranjang** di pojok kanan bawah kartu
3. Notifikasi "Berhasil ditambahkan ke keranjang" akan muncul

**Cara 2: Dari Halaman Detail Produk**

1. Buka halaman detail produk
2. Atur jumlah dengan tombol +/-
3. Klik tombol **"Tambah ke Keranjang"**
4. Notifikasi sukses akan muncul

**Cara 3: Beli Langsung**

1. Dari halaman detail, klik **"Beli Langsung"**
2. Produk ditambahkan ke keranjang
3. Otomatis redirect ke halaman keranjang

**Validasi Otomatis:**

- Jika belum login → Modal login akan muncul
- Jika stok habis → Tombol disabled, pesan "Stok Habis"
- Jika melebihi stok → Pesan error jumlah melebihi stok

**Indikator Keranjang:**

- Badge angka di ikon keranjang (navbar) menunjukkan total item
- Badge otomatis update saat ada perubahan

**Penyimpanan Data Keranjang:**

- Data keranjang disimpan di **Local Storage** browser
- Data tidak hilang saat refresh halaman
- Data tetap tersimpan hingga logout atau hapus manual

---

## 6. PROSES CHECKOUT DAN PEMESANAN

### 6.1 Halaman Checkout

**Gambar 6.1: Halaman Checkout**

Halaman Checkout adalah tahap akhir sebelum membuat pesanan.

**Akses:** Klik tombol **"Lanjut ke Checkout"** dari halaman keranjang

**Syarat Akses Checkout:**

**Layout Halaman Checkout:**

| Posisi    | Elemen                                            |
| --------- | ------------------------------------------------- |
| Header    | Judul "Checkout Pesanan" + tombol kembali ke Cart |
| Section 1 | Daftar produk yang akan dibeli                    |
| Section 2 | Pilihan metode pengambilan                        |
| Section 3 | Pilihan metode pembayaran                         |
| Section 4 | Form alamat (jika delivery)                       |

### 6.4 Konfirmasi Pesanan via WhatsApp

**Gambar 6.4: Alur Konfirmasi WhatsApp**

Setelah klik **"Buat Pesanan"**, sistem akan:

1. **Validasi Data:**

   - Cek nama dan nomor telepon customer
   - Cek alamat (jika delivery)
   - Cek metode pembayaran
   - Cek bank (jika transfer)

2. **Proses di Backend:**

   - Membuat record Order baru
   - Membuat OrderItem untuk setiap produk
   - Mengurangi stok produk
   - Generate nomor pesanan unik
   - Membuat payment record dengan status "pending"
   - Set expiry time (10 menit untuk pembayaran)

3. **Generate WhatsApp URL:**
   Backend membuat URL WhatsApp dengan format pesan:

   ```
   🛒 *KONFIRMASI PESANAN BALETANI*

   📋 *Detail Pesanan*
   No. Order: ORD-XXXXXX
   Tanggal: [Tanggal Order]
   Nama: [Nama Customer]
   No. HP: [Nomor HP]

   📦 *Produk yang Dipesan:*
   1. [Nama Produk]
      Qty: [X] × Rp XXX = Rp XXX
   2. [Nama Produk]
      Qty: [X] × Rp XXX = Rp XXX

   💰 *Rincian Pembayaran:*
   Subtotal: Rp XXX
   Ongkir: Rp XXX
   ─────────────────
   *TOTAL: Rp XXX*

   🚚 *Metode Pengiriman:*
   [Self Pickup / Delivery]
   Alamat: [Alamat jika delivery]

   💳 Pembayaran: [Metode]
   ```

   **Detail Pesan untuk Setiap Metode Pembayaran:**

   **A. Jika Pilih Transfer Bank:**
   Pesan akan menampilkan detail rekening:

   ```
   💳 *Metode Pembayaran:*
   🏦 Transfer Bank [BRI/BCA/MANDIRI]

   *SILAKAN TRANSFER KE:*
   Bank: [BRI/BCA/MANDIRI]
   No. Rek: [Nomor Rekening Toko]
   a/n: BaleTani Fresh Market
   Jumlah: Rp XXX

   ⏰ Batas Waktu: [Tanggal & Jam]

   📸 *Setelah transfer, mohon kirim bukti transfer ke nomor ini*
   ```

   **B. Jika Pilih QRIS:**
   Pesan akan menampilkan:

   ```
   💳 *Metode Pembayaran:*
   📱 QRIS
   Admin akan mengirimkan QR Code atau nomor pembayaran QRIS
   ```

   Customer harus menunggu admin memberikan QR Code atau nomor pembayaran.

   **C. Jika Pilih Tunai/Cash:**
   Pesan akan menampilkan:

   ```
   💳 *Metode Pembayaran:*
   💵 Cash (Bayar di Tempat)
   Pembayaran dilakukan saat pengambilan/pengiriman barang
   ```

   **Catatan Penting:**

   - Untuk **Transfer Bank**: Nomor rekening langsung ditampilkan di pesan WhatsApp
   - Untuk **QRIS**: Customer harus menunggu admin memberikan QR Code atau nomor pembayaran
   - Untuk **Tunai/Cash**: Tidak ada info tambahan, bayar di tempat
   - Timer pembayaran **HANYA berlaku untuk Transfer Bank dan QRIS** (10 menit)
   - Pembayaran **Tunai/Cash** tidak ada batas waktu

4. **Redirect ke WhatsApp:**

   - Browser membuka WhatsApp Web/App
   - Pesan sudah terisi otomatis
   - Customer tinggal kirim pesan

5. **Redirect ke Order Success:**
   - Setelah 1 detik, redirect ke halaman sukses

**Alur Data (FE → BE):**

```
POST /api/customer/orders/create
Body: {
  customer_name: string,
  customer_phone: string,
  delivery_method: "self_pickup" | "delivery",
  delivery_address: string | null,
  delivery_notes: string | null,
  payment_method: "qris" | "transfer" | "cash",
  bank_name: "BRI" | "BCA" | "MANDIRI" | null,
  items: [{ product_id, quantity }]
}
Response: {
  success: true,
  data: {
    order: { id, order_number, status, ... },
    whatsapp: { url, message }
  }
}
```

### 6.5 Halaman Order Success

**Gambar 6.5: Halaman Order Success**

Halaman konfirmasi bahwa pesanan berhasil dibuat.

**Elemen-elemen Halaman:**

| --- | -------------------- | ------------------------------------------------------- |
| 1   | Ikon Sukses          | Checkmark hijau besar                                   |

| 3   | Nomor Pesanan        | Contoh: ORD-20251210-XXXXX                              |
| 4   | Instruksi Pembayaran | Detail pembayaran sesuai metode yang dipilih            |
| 5   | Timer Pembayaran     | Countdown 10 menit (khusus Transfer & QRIS)             |
| 6   | Info Pembayaran      | Instruksi untuk menghubungi admin (untuk Transfer/QRIS) |
| 7   | Tombol WhatsApp      | Buka WhatsApp lagi jika perlu                           |
| 8   | Tombol Riwayat       | Lihat riwayat pesanan                                   |
| 9   | Tombol Belanja Lagi  | Kembali ke katalog produk                               |

**Instruksi Pembayaran Berdasarkan Metode:**

**A. Transfer Bank:**

1. Hubungi admin Balétani via WhatsApp untuk info rekening
2. Admin akan memberikan nomor rekening bank (BRI/BCA/MANDIRI)
3. Buka aplikasi mobile banking
4. Transfer ke rekening yang diberikan admin
5. Nominal harus **SESUAI PERSIS** dengan total pesanan
6. Screenshot bukti transfer
7. Kirim bukti ke admin via WhatsApp
8. Tunggu konfirmasi dari admin

**B. QRIS:**

1. Hubungi admin Balétani via WhatsApp untuk info pembayaran QRIS
2. Admin akan memberikan QR Code atau nomor untuk pembayaran
3. Scan QR Code atau gunakan nomor yang diberikan
4. Masukkan nominal sesuai total pesanan
5. Konfirmasi pembayaran di aplikasi e-wallet
6. Screenshot bukti pembayaran
7. Kirim bukti ke admin via WhatsApp
8. Tunggu konfirmasi dari admin

**C. Tunai/Cash:**

1. **TIDAK ada timer pembayaran** (bayar di tempat)
2. Siapkan uang sesuai total pesanan
3. Datang ke toko untuk ambil barang (Self Pickup)
4. Atau tunggu kurir datang (Delivery)
5. Bayar langsung kepada kasir/kurir

**Catatan Penting:**

- Timer pembayaran **HANYA untuk Transfer & QRIS** (10 menit)
- Pembayaran **Tunai/Cash tidak ada batas waktu**
- Pesanan dengan Transfer/QRIS akan **otomatis dibatalkan** jika tidak dikonfirmasi dalam 10 menit
- Stok akan dikembalikan otomatis jika pesanan dibatalkan
- Setelah countdown habis, sistem akan memanggil endpoint cancel otomatis

## 11. TROUBLESHOOTING DAN FAQ TEKNIS

### 11.1 Masalah Umum dan Solusi

**Q: Tidak bisa login, muncul "Nomor telepon atau password salah"**

- Pastikan format nomor telepon benar (08xx, 62xxx, atau +62xxx)
- Coba reset password jika lupa
- Pastikan akun sudah terdaftar

**Q: Keranjang tiba-tiba kosong**

- Keranjang disimpan di browser, bisa hilang jika clear cache
- Login ulang tidak mengembalikan keranjang
- Tambahkan kembali produk yang diinginkan

**Q: Tidak bisa menambah produk ke keranjang**

- Pastikan sudah login
- Cek apakah stok masih tersedia
- Coba refresh halaman

**Q: Tombol checkout tidak berfungsi**

- Pastikan keranjang tidak kosong
- Pastikan koneksi internet stabil
- Coba clear cache browser dan reload

**Q: WhatsApp tidak terbuka setelah checkout**

- Pastikan WhatsApp terinstall di device
- Coba buka manual dari halaman Order Success
- Salin pesan dan kirim manual ke nomor Balétani

**Q: Pesanan otomatis dibatalkan**

- Pesanan dengan metode **Transfer/QRIS** dibatalkan jika tidak dikonfirmasi dalam 10 menit
- Pesanan dengan metode **Tunai/Cash** tidak akan dibatalkan otomatis
- Buat pesanan baru dan segera lakukan pembayaran & konfirmasi ke admin

**Q: Halaman loading terus / blank**

- Coba refresh halaman (F5 atau Ctrl+R)
- Clear cache browser
- Coba browser berbeda
- Cek koneksi internet

### 11.2 Kontak Bantuan Teknis

Jika mengalami masalah yang tidak dapat diselesaikan:

1. **WhatsApp:** Hubungi CS Balétani
2. **Email:** Kirim detail masalah via form kontak
3. **Jam Respon:** Sesuai jam operasional toko

**Informasi yang Perlu Disiapkan:**

- Screenshot error (jika ada)
- Nomor telepon terdaftar
- Nomor pesanan (jika terkait pesanan)
- Langkah-langkah yang sudah dilakukan
