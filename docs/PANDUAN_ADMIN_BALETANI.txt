1. LOGIN ADMIN
================================================================================

URL: /admin/login

Langkah-langkah login:

1. Buka halaman /admin/login
2. Isi formulir login:

   - NOMOR TELEPON
     * Masukkan nomor telepon admin
     * Format: bisa langsung tanpa perlu normalisasi
   
   - PASSWORD
     * Masukkan password Anda
     * Klik ikon mata untuk lihat/sembunyikan password

3. Klik tombol "Masuk"
4. Jika berhasil, Anda akan diarahkan ke Dashboard Admin

CATATAN KEAMANAN:
- Rate limiter aktif (mencegah brute force)
- Token JWT dengan expiry time
- Auto-logout saat token expired

================================================================================
2. DASHBOARD
================================================================================

URL: /admin/dashboard

Dashboard menampilkan ringkasan dan statistik toko secara real-time.

A. STATISTIK UTAMA (8 KARTU STATISTIK)
--------------------------------------

Baris 1 - Primary Metrics:
1. Pendapatan Hari Ini - Total revenue dengan trend bulanan
2. Transaksi Hari Ini  - Jumlah order dengan trend bulanan
3. Total Pelanggan     - Jumlah customer terdaftar
4. Produk Aktif        - Jumlah produk siap dijual

Baris 2 - Action Required:
5. Pengadaan Pending   - Butuh approval
6. Pembayaran Pending  - Menunggu konfirmasi

B. SECTION PESANAN TERBARU
--------------------------
- Menampilkan 5 pesanan terbaru
- Kolom: Order #, Pelanggan, Total, Status
- Badge status: Lunas (hijau), Pending (kuning), Gagal (merah), dll
- Tombol "Lihat Semua →" ke halaman Orders

C. SECTION STOK MENIPIS
-----------------------
- Menampilkan 5 produk dengan stok rendah
- Kolom: Produk, Kategori, Stok, Status
- Status stok: Kritis (merah), Rendah (kuning), Aman (hijau)
- Tombol "Kelola Stok →" ke halaman Products

3. MANAJEMEN PRODUK
================================================================================

URL: /admin/products

Halaman untuk mengelola semua produk toko.

A. STATISTIK PRODUK (4 KARTU)
-----------------------------
1. Total Produk   - Jumlah semua produk
2. Produk Aktif   - Produk yang aktif dijual
3. Stok Rendah    - Produk dengan stok <= 10
4. Stok Habis     - Produk dengan stok 0

B. FILTER DAN PENCARIAN
-----------------------
- Search Box      : Cari berdasarkan nama produk
- Filter Kategori : Pilih kategori tertentu
- Filter Status   : Aktif / Nonaktif
- Filter Tipe     : Standar / Paket / Promo

C. TABEL PRODUK
---------------
Kolom yang ditampilkan:
- Gambar    : Thumbnail produk
- Nama      : Nama produk lengkap
- Kategori  : Kategori produk
- Harga     : Harga jual
- Stok      : Jumlah stok tersedia
- Status    : Aktif/Nonaktif (badge)
- Aksi      : View, Edit, Delete

D. OPERASI PRODUK
-----------------

1. TAMBAH PRODUK BARU
   - Klik tombol "Tambah Produk" (hijau, pojok kanan atas)
   - Isi form:
     * Nama Produk (wajib, min 3 karakter)
     * Kategori (wajib, pilih dari dropdown)
     * Tipe Produk (Standar/Paket/Promo)
     * Harga (wajib, angka)
     * Stok (wajib, angka)
     * Satuan (kg, pcs, ikat, dll)
     * Deskripsi (opsional)
     * Upload Gambar (JPG/PNG, max 5MB)
     * Status (toggle Aktif/Nonaktif)
   - Klik "Simpan"

2. LIHAT DETAIL PRODUK
   - Klik ikon mata (eye) di kolom aksi
   - Modal detail akan muncul dengan info lengkap

3. EDIT PRODUK
   - Klik ikon pensil di kolom aksi
   - Form edit muncul dengan data pre-filled
   - Ubah data yang diperlukan
   - Klik "Simpan"

4. HAPUS PRODUK
   - Klik ikon tempat sampah di kolom aksi
   - Konfirmasi akan muncul
   - Klik "Hapus" untuk konfirmasi
   - (Soft delete - data tidak benar-benar hilang)

5. MANAJEMEN DISKON
================================================================================

URL: /admin/discounts

Halaman untuk mengelola diskon/promo produk.

A. STATISTIK DISKON
-------------------
- Total Diskon
- Diskon Aktif
- Diskon Nonaktif
- Tipe Persentase
- Tipe Fixed Amount

B. STATUS DISKON
----------------
- Active    (Hijau)  : Diskon sedang berlaku
- Expired   (Merah)  : Diskon sudah berakhir
- Upcoming  (Biru)   : Diskon belum dimulai
- Inactive  (Abu)    : Dinonaktifkan manual

C. FILTER DAN PENCARIAN
-----------------------
- Search Box    : Cari nama diskon
- Filter Status : Active / Expired / Upcoming
- Filter Tipe   : Percentage / Fixed Amount

D. TABEL DISKON
---------------
Kolom yang ditampilkan:
- Nama Diskon   : Nama/judul promo
- Tipe          : Persentase atau Nominal
- Nilai         : Besar diskon (% atau Rp)
- Periode       : Tanggal mulai - selesai
- Status        : Badge warna
- Aksi          : View, Edit, Assign Produk, Delete

E. OPERASI DISKON
-----------------

1. TAMBAH DISKON BARU
   - Klik tombol "Tambah Diskon"
   - Isi form:
     * Nama Diskon (wajib)
     * Tipe: Percentage (%) atau Fixed Amount (Rp)
     * Nilai (angka diskon)
     * Tanggal Mulai (wajib)
     * Tanggal Selesai (wajib, harus > tanggal mulai)
     * Status (Aktif/Nonaktif)
   - Klik "Simpan"

2. ASSIGN PRODUK KE DISKON
   - Klik ikon kubus di kolom aksi
   - Modal pilih produk muncul
   - Centang produk yang ingin didiskon
   - Bisa search produk
   - Preview harga asli vs harga setelah diskon
   - Klik "Simpan"

3. EDIT & HAPUS
   - Sama seperti kategori

6. MANAJEMEN PESANAN (ORDERS)
================================================================================

URL: /admin/orders

Halaman untuk mengelola semua pesanan (online & offline).

A. STATISTIK PESANAN
--------------------
- Total Orders
- Total Revenue
- Rata-rata Order
- Pesanan Hari Ini

B. FILTER PESANAN
-----------------
- Search Box       : Cari nomor order, nama, telepon
- Status Order     : Pending, Processing, Completed, Cancelled
- Status Pembayaran: Pending, Paid, Failed
- Tipe Order       : Online / Offline
- Metode Bayar     : Cash, Transfer, QRIS
- Metode Delivery  : Self Pickup, Delivery
- Range Tanggal    : Dari - Sampai

C. TABEL PESANAN
----------------
Kolom yang ditampilkan:
- Order #         : Nomor pesanan
- Tanggal         : Waktu order dibuat
- Customer        : Nama dan telepon
- Total           : Total pembayaran
- Status Order    : Badge status
- Status Bayar    : Badge status
- Aksi            : View, Update Status

D. OPERASI PESANAN
------------------

1. LIHAT DETAIL PESANAN
   - Klik ikon mata di kolom aksi
   - Modal detail menampilkan:
     * Info customer
     * Daftar produk yang dipesan
     * Metode pengiriman & alamat
     * Metode pembayaran
     * Timeline status pesanan

2. UPDATE STATUS
   - Klik ikon edit di kolom aksi
   - Pilih status baru:
     * pending_payment - Menunggu pembayaran
     * paid            - Terbayar
     * processing      - Sedang diproses
     * ready_for_pickup - Siap diambil
     * out_for_delivery - Dalam pengiriman
     * completed       - Selesai
     * cancelled       - Dibatalkan
   - Klik "Update"

3. TAMBAH ORDER OFFLINE
   - Klik tombol "Tambah Order"
   - Form order offline:
     * Nama Customer
     * Nomor Telepon
     * Pilih Produk & Quantity
     * Metode Bayar (Cash default)
   - Klik "Buat Order"

13. LAPORAN INVENTORI
================================================================================

URL: /admin/reports/inventory

Halaman untuk melihat laporan stok dan pergerakan barang.

-----------------

--------------------
Kolom yang ditampilkan:
- Produk     : Nama produk
- Kategori   : Kategori
- Stok       : Jumlah tersedia
- Status     : Badge (Habis/Rendah/Normal)
- Harga      : Harga jual
- Nilai      : Stok x Harga

D. TABEL PERGERAKAN STOK
------------------------
Kolom yang ditampilkan:
- Tanggal
- Produk
- Tipe Pergerakan:
  * Masuk (Pengadaan)   - Stok bertambah
  * Keluar (Penjualan)  - Stok berkurang
  * Penyesuaian         - Adjustment manual
  * Kadaluarsa          - Stok expired
- Quantity
- Keterangan

14. LOGOUT
================================================================================

Cara logout dari sistem admin:

1. Klik tombol "Logout" di bagian bawah sidebar
2. Atau klik nama admin di header, lalu pilih "Keluar"
3. Anda akan diarahkan ke halaman login admin

SETELAH LOGOUT:
- Token autentikasi dihapus
- Session berakhir
- Harus login ulang untuk akses dashboard

================================================================================
                           TIPS KEAMANAN ADMIN
================================================================================

1. Jangan share password ke orang lain
2. Gunakan password yang kuat (kombinasi huruf, angka, simbol)
3. Logout setelah selesai menggunakan
4. Jangan akses dashboard di komputer publik/umum
5. Laporkan jika ada aktivitas mencurigakan ke Super Admin

================================================================================
                         ROLE & HAK AKSES (RBAC)
================================================================================

Setiap role memiliki permission berbeda:

SUPER_ADMIN:
- Akses penuh ke SEMUA fitur
- Bisa kelola admin lain

INVENTORY_ADMIN:
- Kelola Produk, Kategori, Diskon
- Kelola Pengadaan
- Lihat Laporan Inventori

CASHIER:
- Kelola Orders (termasuk offline order)
- Lihat Laporan Penjualan

WHATSAPP_ADMIN:
- Kelola Orders (update status)
- Kelola Pesan Kontak

FINANCE_ADMIN:
- Lihat Dashboard
- Lihat semua Laporan
