# 💳 Payment Bank Integration - Virtual Account System

## 📝 Overview

Integrasi sistem pembayaran Virtual Account (VA) untuk transfer bank dengan pilihan BRI, BCA, dan MANDIRI. Sistem ini memungkinkan customer untuk memilih bank saat checkout dan otomatis generate nomor Virtual Account.

---

## ✅ Fitur yang Sudah Diimplementasi

### 1. **Backend API**

- ✅ PaymentDetail model dengan auto-generate VA
- ✅ Customer checkout dengan pilihan bank (BRI/BCA/MANDIRI)
- ✅ Admin dapat melihat info payment detail (bank + VA)
- ✅ Order history customer menampilkan payment detail

### 2. **Frontend Customer**

- ✅ Checkout page dengan pilihan bank (UI card grid)
- ✅ Order success page menampilkan VA dengan tombol copy
- ✅ Purchase history menampilkan payment method dan bank

### 3. **Frontend Admin**

- ✅ Order list menampilkan payment_detail
- ✅ Order detail modal menampilkan bank dan VA number
- ✅ Dashboard stats compatible dengan payment detail

## 🎯 User Flow

### **Customer Checkout Flow**

1. **Cart → Checkout**

   - Customer klik "Checkout" dari cart page
   - Redirect ke `/checkout`

2. **Pilih Metode Pengiriman**

   - Self Pickup (gratis) atau Delivery (Rp 10.000)
   - Jika Delivery, input alamat (required)

3. **Pilih Metode Pembayaran**

   - **QRIS** (belum implemented)
   - **Transfer Bank** ← PILIH INI
   - **Tunai** (COD)

4. **Pilih Bank (jika Transfer)**

   - Grid 3 bank: BRI, BCA, MANDIRI
   - Klik salah satu bank
   - Validasi: harus pilih bank sebelum submit

5. **Submit Order**

   - POST `/api/customer/orders/create`
   - Request body includes `bank_name`
   - Backend generate VA otomatis

6. **Order Success Page**
   - Tampilkan VA number dengan format besar
   - Tombol "Salin" untuk copy VA
   - Informasi bank, account name, total, expired time
   - Tombol WhatsApp untuk konfirmasi ke admin

---

### **Admin Order Management Flow**

1. **Order List**

   - Tampilkan kolom payment_method
   - Filter by payment_method (transfer/qris/tunai)
   - Kolom bank muncul jika method = transfer

2. **Order Detail**

   - Klik order untuk lihat detail
   - Section "Payment Information" menampilkan:
     - Method
     - Status
     - **Bank** (jika transfer) ← TAMBAHAN
     - **Virtual Account** (jika transfer) ← TAMBAHAN
     - Account Name
     - Paid At (jika sudah bayar)

3. **Update Status**
   - Admin verify payment (manual/webhook)
   - Update `payment_status` → `paid`
   - Update `order_status` → `processing`

## 🔐 Security & Validation

### Backend Validation

```javascript
// 1. Validasi bank_name
if (!bank_name || !["BRI", "BCA", "MANDIRI"].includes(bank_name)) {
  return res.status(400).json({
    success: false,
    message: "Pilih bank terlebih dahulu (BRI/BCA/MANDIRI)",
  });
}

// 2. Virtual Account generation (di model)
static generateVA(bankName) {
  const bankCodes = {
    BRI: "002",
    BCA: "014",
    MANDIRI: "008",
  };
  const bankCode = bankCodes[bankName];
  const timestamp = Date.now().toString().slice(-10);
  const random = Math.floor(Math.random() * 1000000).toString().padStart(6, "0");
  return `${bankCode}${timestamp}${random}`.slice(0, 16);
}

// 3. Expiry time (24 jam)
static getExpiryTime() {
  const expiry = new Date();
  expiry.setHours(expiry.getHours() + 24);
  return expiry;
}
```

## 📊 Database Structure

### **payment_details Table**

```sql
CREATE TABLE payment_details (
  id CHAR(36) PRIMARY KEY,
  order_id CHAR(36) NOT NULL,
  payment_method VARCHAR(50) NOT NULL,
  bank_name VARCHAR(50),          -- BRI/BCA/MANDIRI
  virtual_account VARCHAR(50),    -- Auto-generated
  account_name VARCHAR(255),      -- "BaleTani Fresh Market"
  payment_status ENUM('pending', 'paid', 'failed', 'expired'),
  paid_at DATETIME,
  expired_at DATETIME,            -- 24 hours from creation
  created_at DATETIME,
  updated_at DATETIME,
  FOREIGN KEY (order_id) REFERENCES orders(id)
);
```

### **Virtual Account Format**

```
BRI:     002 + timestamp(10) + random(6) = 16 digits
BCA:     014 + timestamp(10) + random(6) = 16 digits
MANDIRI: 008 + timestamp(10) + random(6) = 16 digits

Example:
- BRI:     0021705449876543
- BCA:     0141705449876543
- MANDIRI: 0081705449876543
```
